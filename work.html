Hydroficient IoT Cyber Defense Externship

Build, hack, and defend real IoT infrastructure, then hand your security playbook to an actual company. You'll launch realistic cyberattacks, from spoofing and replay attacks to unauthorized shutoffs, and implement defenses like TLS and mTLS.

Python Programming Data Analysis Threat Modeling Dashboard Development

Overview

During my externship at Hydroficient, I developed and executed cyber defense strategies for IoT infrastructure. I conducted realistic cyberattacks and implemented security measures, culminating in a comprehensive security playbook tailored for a real-world application. This experience deepened my understanding of IoT technologies and the critical need for robust security protocols.

Project breakdown

The externship scenario described a hotel's water IoT system. I inventoried assets, mapped data flows, applied STRIDE to each component, and wrote an executive summary listing the top three prioritized threats and recommended fixes.

Google Docs Access ↗

I completed Colab notebooks that implemented Python data structures, control flow, and functions, cleaned loan-style data with pandas, parsed JSON into normalized tables, and produced sensor log generator scripts. Deliverables included runnable Colab and Drive files.

Google Colab Open Link ↗

I built a local MQTT pipeline, ran Mosquitto, wrote Python publishers and a dashboard subscriber, then intercepted and recorded plain-text messages. I documented captured topics, JSON payloads, and vulnerabilities (no auth, no encryption, replay risks) with remediation notes.

Google Docs Access ↗

Situation: sensor traffic was exposed on the hotel network. Task: secure the MQTT pipeline. Action: generated a CA and signed server certificates, configured Mosquitto on port 8883, and updated Python clients to use TLS. Result: insecure connections were rejected and traffic was unreadable to an eavesdropper.

Google Docs Access ↗

The work reviewed mTLS controls, produced a Device Provisioning Policy that specified certificate generation, onboarding steps, rotation schedule, revocation procedures, and per-device records for the water monitoring system.

Google Docs Access ↗

The project tested three replay protections against immediate, delayed, and tampered replays. I ran experiments, recorded that only the combined defenses blocked all attack types, and recommended deploying all three across subscriber nodes.

Google Docs Access ↗

I compiled the IoT Security Capstone presentation that documented the threat model, four-layer defense architecture, three-phase attack simulator, experiment setup, and results showing 0 successful attacks and real-time dashboard alerts.
